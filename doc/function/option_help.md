# option_help

## Print help for options defined in options specification

This is mainly used by the [`help`](help.md) output.


### Usage

```bash
option_help <spec>
<spec> lines := <short-letter>|- <long-word> <type>|- <description>
```

### Output (stdout)

- List of options for help output
