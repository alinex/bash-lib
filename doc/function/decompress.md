# decompress

## Uncompress data stream using multiple algorithms.

### Usage

```bash
decompress [<string>]
<string> | decompress
```

### Options

```bash
-f, --file <path>          # file to read from
-o, --output <path>        # file to write to
-t, --tool <compression>   # compression: gzip, zip,...
```
