# horizontal_line

## Show a horizontal line

It will go over the full width of terminal, but be at least 60 characters wide.

Format can be:

- light (default) ──────────
- bold ━━━━━━━━━━
- double ══════════
- half ▄▄▄▄▄▄▄▄▄▄
- full ██████████

### Usage

```bash
horizontal_line [<format>]
```

### Output (stdout)

────────── # over full width of terminal
