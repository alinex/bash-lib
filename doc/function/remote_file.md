# remote_file

## Run local script on remote



### Usage

```bash
remote_file [<options>] <file>
<file> | remote_file [<options>]
```

### Options

```bash
# following options, only before `<file>`
-l, --login <user>
-h, --host <host>
-j, --jump <user>@<host>
```

### Globals

- `$server`
- `$login` - default is "operator"

### Output (stdout)

- passed through
