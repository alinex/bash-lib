# semver

## Parse semantic version number

### Usage

```bash
semver <string>
<string> | semver
```

### Output (stdout)

The following fields separated by spaces:

- `<major>`
- `<minor>`         or "" if undefined
- `<patch>`         or "" if undefined
- `<prerelease>`    or "" if undefined
- `<build>`         or "" if undefined
