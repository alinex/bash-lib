# boot_wait

## Wait till reboot is finished

### Usage

```bash
boot_wait [<options>]
```

### Options

```bash
-l, -login <user>
-h, -host <host>
-j, -jump <user>@<host>
-q, -quiet
```

### Globals

- - `$server`
- - `$login` - default is "operator"
