# ip_extern

## Run  os detection and set the constants

The following formats are possible:

- data - all values with `<name>	<value>`
- country
- countryCode
- region
- regionName
- city
- zip
- lat
- lon
- timezone
- isp
- org
- as
- ip

### Usage

```bash
ip_extern <format>
```

### Output (stdout)

`<tsv-table>` for data
`<value>` else
