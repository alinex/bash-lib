# ssh_allowed

## Get allowed ssh keys

### Usage

```bash
sudo_info [<user>]...
```

### Output (stdout)

`<tsv with header>`
User                	Comment             	            Type      Key
operator            	alexander.schilling@my-company.com	ssh-rsa   AAAAB3NzaC1yc????


### Description


This lists all allowed ssh keys for the users.
