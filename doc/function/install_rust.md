# install_rust

## Build and Install Rust Repository

### Usage

```bash
install_rust [options] <repo> -- <flags>
```

### Options

```bash
-n, --nightly   # build on nightly instead stable rust
```

### Description


This will install/update rust, clone the repo, build the binary and install it.

**Attention: It is always better to use pre-build packages because newer code may break something and you may have some problems to get it build correctly again.**
